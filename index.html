Brass AI Axioms

Where your AI coding agent's "done" stops meaning done.

Your agent says done. The code's almost right, so it ships — then something breaks in prod that "done" should've caught. These four free tools (the Shearpin Process) check what the agent actually built against what you actually asked for, at every stage, before you merge.

  • The Axioms Live A 30-line rules file — paste into CLAUDE.md, .cursorrules, or AGENTS.md. Makes your agent prove a change works before it calls itself done, stops it over-building, and makes it own up to what broke. GitHub →
  • Blacksmith Live Runs the build step-by-step against your original spec, so if the agent drifts off-task you catch it at step 3, not buried in 40 files of "done." GitHub →
  • VibeValve Coming soon Makes the agent re-check its own bug fix against what you actually asked for, clause by clause, before you hit merge.
  • Gauge Coming soon Fact-checks every claim your agent makes about its own output — if it can't verify a claim, Gauge doesn't pass it.
