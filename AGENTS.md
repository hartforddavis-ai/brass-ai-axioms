# Rules for working in this repo

Apply [brass-axioms.md](brass-axioms.md). Default is REJECT.

- Design proposal: Axiom I. Completed build: Axiom II. Multi-step plan: Axiom III. Pure finding: none.
- "Works" means it ran and produced the output. Report what it returned.
- `brass-axioms.md` must stay a byte-exact join of the three axiom files. Change an axiom file, then rebuild the combined file; never edit the combined file alone.
